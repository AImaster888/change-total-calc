# 工程契約變更簽辦計算系統

**版本：v1.3.0　　發布日期：2026-07-27**

工程契約變更簽辦計算系統，提供公共工程契約變更作業使用，協助辦理：

- 契約追加減金額計算
- 新增項目試算
- 承商利潤與營業稅驗證
- 契約變更金額彙算
- 計算歷程輸出
- 簽辦附件生成
- DOCX/PDF 匯出

本系統以「工程契約變更簽辦自動化」為核心目標，並依工程實務及公務行政流程設計。

---

# 系統特色

## 1. 契約變更金額自動計算

系統可依輸入資料自動計算：

| 項目 | 說明 |
|---|---|
| A1 | 原契約金額 |
| A2 | 原契約工項追加金額 |
| A3 | 原契約工項追減金額 |
| A4a | 新增項目（不議價） |
| A4b | 新增項目（議價） |
| A4 | 新增項目總額 (A4a + A4b) |
| A5 | 承商利潤及保險費 |
| A6 | 職業安全衛生費 |
| A7 | 材料檢試驗費 |
| B1 | 變更項目總和 |
| B2 | 變更總金額 |
| B3 | 營業稅 |
| B4 | 本次變更金額 |
| B5 | 變更後契約總金額 |

---

# 計算原則（取位規則）

- **各項計算一律無條件捨去至小數 2 位，全程不做四捨五入**
  （A4、B1、A5、B2、B3、B4、B5、012/0B 分攤、新增項目佔比皆適用）。
- **例外**：新增項目「含稅金額」維持**無條件捨去至整數**。
- 需要調整金額時，由 **012 承商利潤**與 **0B 營業稅**欄位手動修正，不靠取位進位來湊數。
- 負數（追減）的無條件捨去朝零，例：`-50000.559` → `-50000.55`。

> **實作註記**：取位以字串進行（`cut2`），**不使用** `Math.floor(n * 100) / 100`。
>
> 1. `Math.floor(n*100)/100` 會吃 IEEE-754 尾差：`(2900/1000000)*100*100` 實際為
>    `28.999999999999996`，會把佔比 `0.29%` 誤捨成 `0.28%`、012 分攤由 `290` 變 `280`。
> 2. 浮點防線必須用**有效位數**（`toPrecision(15)`）而非固定小數位。誤差與數值量級成正比：
>    兩千六百萬的量級誤差約 `1e-8`，固定 10 位小數的防線會失效——
>    `25000000 + 1400071.47` 的浮點值為 `...46999999988`，會被誤捨成 `.46`，**少一分**。
>
> 以上兩點皆有回歸測試涵蓋，見 `test-calc.js`。

# 計算公式

## 變更項目總和

B1 = A2 + A3 + A4a + A4b

---

## 承商利潤

A5 = B1 × 承商利潤率 (%)

---

## 變更總金額

B2 = B1 + A5 + A6 + A7

---

## 營業稅

B3 = B2 × 5%

---

## 本次變更金額

B4 = B2 + B3

---

## 變更後契約總金額

B5 = A1 + B4

---

# 驗證機制

系統內建工程契約變更常用驗證規則。

## 利潤率檢核

- 追加時：
  - 承商利潤不得超過 B1 × 契約利潤率
- 追減時：
  - 僅檢核正負方向，允許多扣，不檢核幅度

---

## 營業稅檢核

- 營業稅以變更總金額 5% 為原則
- 追加時不得超過上限
- 追減時允許多扣（不顯示不足警示）

---

## 正負值檢核

追加時（B1 > 0）：

- 012 承商利潤
- 013 職安衛
- 014 材料檢試驗

應為正值。

追減時（B1 < 0）：

- 012 承商利潤
- 013 職安衛
- 014 材料檢試驗

應為負值。

- 012 承商利潤分攤

- 營業稅計算
- 含稅總價計算

# 新增項目議價管理（開發中）

後續將新增：

| 欄位 | 說明 |
|---|---|
| 是否議價 | 是 / 否 |
| 不議價原因 | 依原契約單價、無市場價差等 |
| 議價說明 | 供簽辦文字輸出 |

系統將可自動生成：

```text
本新增項目經檢討未涉市場供應價差，
仍依原契約單價編列，
不另辦理議價。
```

# CSV 匯出／匯入（供 Excel 比對與交接）

系統提供兩種匯出，皆為 UTF-8 BOM 編碼的 CSV，Excel 直接開啟不會中文亂碼。

## 1. 匯出目前計算表（上方按鈕列，隨時可用）

匯出畫面上這一件案子的逐項比對表，欄位為：

| 項目 | 初算值 | 調整值 | 差額 | 驗證訊息 |
|---|---|---|---|---|

並附「新增項目含稅計算」區塊（佔比、012/013/014 分攤、營業稅、含稅金額）。

適用於：與廠商送審文件逐項核對、簽辦附件。

## 2. 匯出計算紀錄（儲存紀錄區，需先儲存至少一筆）

把已儲存的多件案子橫向攤開成一列一案，每個欄位都含「初算」與「調整」兩欄，末欄為 B5 差額。

適用於：跨案件彙整、統計。

> 儲存紀錄需先填寫「案件名稱」，未填會出現提示。

## 3. 匯入 CSV（上方按鈕列「📂 匯入 CSV」）

把上述**兩種**匯出檔讀回系統，供跨電腦、跨承辦人交接使用。系統依檔案內容自動辨識格式：

| 匯入的檔案 | 系統行為 |
|---|---|
| 匯出目前計算表 | 還原成畫面上的計算表（含右欄手動調整與新增項目分攤）；畫面已有資料時會先詢問是否覆蓋 |
| 匯出計算紀錄 | 逐列還原後**併入**儲存紀錄（不清除既有紀錄），再按「載入」即可帶回畫面 |
| 其他 CSV | 顯示無法辨識的提示，不動到現有資料 |

匯入行為說明：

- 以「初算值」欄還原輸入欄位，以「調整值」欄還原右欄手動覆寫。
- **只有「調整值 ≠ 初算值」才會標記為「已改」**。若當初手動填入的數字剛好等於公式值，匯入後不會顯示「已改」標記，但計算結果完全相同。
- 新增項目的 012/013/014 分攤同樣依「採用值」還原；013/014 為 0 視為未填。
- 「匯出計算紀錄」的欄位不含新增項目分攤，該格式匯入後分攤一律為空白，需自行重填。
- 檔案編碼須為 UTF-8（本系統匯出的檔案皆符合）。

匯入完成後會即時重算與重新驗證，因此**驗證警示會一併重現**，不需人工重新檢查。
